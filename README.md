# STATS 506 — Homework 5

Author: Jun Su

This homework implements Wald confidence intervals in R, analyzes 2019 ATP tennis matches, and visualizes U.S. COVID-19 case trends.

## Files

- `HW05.qmd`: Quarto source code and answers.
- `HW05.Rmd`: R Markdown copy of the source.
- `HW05.html`: Rendered report. Open it in a web browser.
- `data/`: Tennis and COVID-19 datasets.

## Run

With R, Quarto, and the required R packages installed, run this command from the repository folder.

```sh
quarto render HW05.qmd
```
